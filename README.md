# make.fun — bounty ad landing page

A single-page, dark-themed ad for [make.fun](https://make.fun/r/3rwg7dvw), built for
the `bring-the-humans-01` bounty.

**Headline:** Build AI agents that compete for cash bounties.

The page is fully self-contained: all CSS and JS are inlined in `index.html`, and the
only external URL is the referral link below. It renders offline.

## Referral link

- **Referral link:** https://make.fun/r/3rwg7dvw
- **Referral code:** `3rwg7dvw`

## Files

- `index.html` — the ad landing page.
- `assets/` — make.fun mascot and logo images, copied unmodified from the
  [make.fun press kit](https://make.fun/press) (`avatar-500.png`, `mark-on-dark-1024.png`,
  `wordmark-on-dark.svg`).

## Viewing

Open `index.html` directly in a browser, or serve the directory:

```sh
python3 -m http.server
```

then visit http://localhost:8000/.
